## Preston Crowe's University Class Projects

_During my time in university, I plan to keep track of the bigger programming projects required by my class to show my work ethic and effort that I put in all of my projects. This repository will be organized by folder per class if there are multiple projects for the class, or just one folder representing the singular project._

**This is the list of the current projects in the repository:**

- Computer Architecture (CS 2340) Term Project - Number Chain { MIPS Assembly }
  - Programmed in MIPS assembly, this project is a fun and interactive board game with a computer player that optimally chooses where to go. Full use case bound checks are implemented with lockout checks, autofills, and other validations.
  - Look at the term project report PDF for the full description on the algorithms and use the user manual to learn how to play the game!
  - **Must use MARS Mips to run this code. Look at the user manual for more instructions.**
- Data Structures and Algorithms (CS 3345)
  - Programming Assignment 1 - Request Management System Help Desk { C++ }
    - This assignment was to learn how to build a queue, stack, binary search tree, and a singly linked list using classes in C++. Generics were not required for this assignment. The program is a terminal console app to write commands that push requests, process them, undo and redo, and search using the four data structures required.
    - **C++ 17 or more is required to run this program.**
  - Programming Assignment 2 - Word Frequency Collector using separate chaining hash tables (with linked lists), binary heaps, and merge sort { C++ }
    - This assignment was to learn how to build a hash table with hash functions, resizing, and more, binary heaps with multiple comparison factors in objects, and merge sort with multiple comparison factors in objects. Generics were not required for this assignment.
    - You are given an array of words. The program will send you a list of the most frequent words in the list ordered by frequency, with the integer tie breaker being alphabetical order for the word itself.
    - The program is a terminal console app with a one-run printed output. You can change the k value and any of the string contents in the 2D vector array to change the result.
    - **DO NOT USE CLANG TO COMPILE, USE CLANG++. C++ 17 or more is required to run this program.**
